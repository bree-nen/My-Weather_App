<h1>🌍 Meteo Global</h1>
<br>
<br>
<p>Meteo Global is a modern weather application designed to provide users with accurate and easy-to-understand weather information for locations around the world.</p>
<br>
<p>The app lets users search for a city and view current conditions, forecasts, and other useful details through a clean, responsive interface.</p>
<br>
<br>

<h2>☃️ Features</h2>
<br>
🌤️ Current Weather — View current temperature and weather conditions.
<br>
🔍 Location Search — Search for weather information by city.
<br>
📅 Weather Forecast — Upcoming weather conditions.
<br>
🌍 Global Locations — Check weather information for cities around the world.
<br>
☄️ Modern UI — Clean and user-friendly interface.
<br>
⚡ Real-Time Data — Weather information is retrieved through a weather API.
